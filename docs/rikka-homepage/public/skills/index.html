Agent Skills

Task-oriented operational guides for AI coding agents writing code with the Rikka Web Components toolkit. 14 skills, each one folder ≈ one task. Follow the [agentskills.io](https://agentskills.io) format (SKILL.md with YAML frontmatter).

Install all 14 skills
  • Run npx skills add yw662/rikka — installs into the agent's skill directory (supports OpenCode, Claude Code, Codex, Cursor, and 67 more).
  • Or browse them at skills.sh.
  • Or read them raw: https://yw662.github.io/rikka/skills/<name>/SKILL.md
  • Machine-readable index: ../llms.txt
  • Start with rikka/SKILL.md (umbrella) — then load one of the task-specific skills below.
